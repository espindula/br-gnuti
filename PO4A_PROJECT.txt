Primeira execução
=================


Comandos para gerar um arquivo Portable Object Template (POT) inicial dentro do
sub diretório "po" do diretório "po4a" (subprojeto "texinfo") (executar todos
como usuário(a) normal):

cd po4a/


cat > po4a.conf << "FIM"

[po_directory] texinfo/po/

[type: texinfo] texinfo/texinfo-ed.7.1-en_US.texi $lang:texinfo/translated/texinfo-ed.7.1-$lang.texi

FIM


mkdir -pv texinfo/{po,translated}


> texinfo/po/pt_BR.pot


( po4a --verbose po4a.conf 2>&1 | tee /tmp/po4a.log.txt && exit "${PIPESTATUS}" )


Ao final da execução, o arquivo "pt_BR.pot" (inicialmente vazio) estará
preenchido com todas as unidades de texto para serem traduzidas. O próximo passo
é o de renomear "pt_BR.pot" para "pt_BR.po" e começar a traduzir as unidades de
texto.
